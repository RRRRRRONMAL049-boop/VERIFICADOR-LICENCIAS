Arrastrar la carpeta a Netlify NO basta.

1. Entra a https://github.com/new
2. Nombre del repo: verificador-licencias
3. Crea el repo (Public)
4. Sube TODOS los archivos de esta carpeta
   (botón "uploading an existing file" o Arrastrar)

5. Entra a Netlify → tu sitio
   semoviccdmx-validartulicencia-gobmx.netlify.app
6. Site configuration → Build & deploy → Continuous deployment
7. Link repository → elige verificador-licencias
8. Publish directory: deja vacío o pon .
